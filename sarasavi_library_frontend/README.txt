# Sarasavi Library Management System - Front End

This is a simple front-end prototype created with only HTML, CSS and JavaScript.

Pages:
- index.html - Login page
- home.html - Main menu / home page
- registration.html - Book registration form

Demo login:
- Username: admin
- Password: admin123

Book data is stored in browser localStorage for demonstration.

How to run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Login using the demo account above.

No database or backend is used yet.
